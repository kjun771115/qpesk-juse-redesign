# 요약노트 템플릿

```markdown
# <영상 제목>
> 채널: <채널> · 길이: <mm:ss> · 링크: <URL> · 작성일: <YYYY-MM-DD>
> 자료: 자막(<manual|auto|gemini>) + 장면분석(<Gemini 모델 | 프레임 시트>)

## 한 줄 요약
<이 영상이 말하는 것 한 문장>

## 핵심 포인트
1. <주장/개념> — <설명 1~2문장> `[mm:ss]`
2. ...

## 흐름 (타임라인)
| 구간 | 내용 | 화면에서 보인 것 |
|---|---|---|
| 00:00–00:15 | ... | ... |

## 따라 하기 (실행 단계)
1. ...
(영상이 방법을 다루지 않으면 이 섹션 생략)

## 용어·도구
- **<용어>**: <정의> `[mm:ss]`

## 복습 질문
1. <질문>  <details><summary>답</summary>…</details>

## 내 생각 / 다음 할 일
- (사용자가 채울 칸)
```

깊이별 분량: `quick` 핵심 포인트 3개·복습 질문 없음 / `standard` 5개·질문 3개 / `deep` 7개 이상·질문 5개 + 각 포인트에 장면 근거 설명.

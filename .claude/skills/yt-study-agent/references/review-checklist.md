# 검수 체크리스트

`review.md` 형식:
```
VERDICT: PASS | FAIL
## 항목별 결과
- [x]/[ ] 항목 — 근거
## 수정 지시 (FAIL일 때, 구체적으로)
1. note.md "<문제 문장>" → <어떻게 고칠지> (근거 transcript [mm:ss])
```

## 사실성 (하나라도 실패하면 FAIL)
- [ ] 핵심 포인트마다 `[mm:ss]`가 있고, 해당 시각의 transcript/scenes 내용과 실제로 일치한다 (무작위 3개 이상 대조)
- [ ] 영상에 없는 주장·수치·도구명이 없다
- [ ] 화면 텍스트·도구명 철자가 scenes.md 원문과 같다

## 완결성
- [ ] 템플릿의 필수 섹션(한 줄 요약, 핵심 포인트, 흐름, 용어)이 있다
- [ ] 타임라인이 영상 전체 구간을 덮는다
- [ ] 깊이 설정에 맞는 분량이다

## 유용성
- [ ] 한 줄 요약만 읽어도 영상 주제를 알 수 있다
- [ ] 실행 단계가 순서대로 따라 할 수 있게 구체적이다 (해당 시)
- [ ] 복습 질문의 답이 노트 안에 있다

## 형식
- [ ] 원문을 길게(2~3문장 이상) 그대로 옮긴 부분이 없다
- [ ] markdown이 깨지지 않는다 (표, details 태그)
